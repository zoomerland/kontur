# Contributing

Start with an issue describing the problem, a minimal synthetic example and the expected behavior. Keep pull requests focused. Never attach real access keys, databases, private project plans or browser profiles.

Preserve the versioned API, revision conflicts, dependency validation and the distinction between reported status and verified facts. Git visualization must not invent ancestry or branch provenance. All new visible UI strings need English, Russian and Simplified Chinese entries.

Run Python tests with `python -m pytest -q` after installing `requirements-dev.txt`. Run the localization test and syntax checks for changed JavaScript. Include the checks and remaining limits in your pull request. AI-assisted contributions are welcome when disclosed and reviewed by their submitter.

Translations: keep stable API IDs and user-entered content unchanged. Translate interface text and help pages; explain any ambiguous term in the pull request.
