Помощь Контура

Монитор переданного состояния проектов для одного владельца. Работает с HTTP-агентом, скриптом или импортом JSON. Модель и Git не нужны.

Доступ

После запуска run.py откройте http://127.0.0.1:8766. Прочитайте созданный ключ в data/api-token.txt локально и введите его в браузере. Все запросы /api/v1 требуют Authorization: Bearer <ключ>. Ключ даёт доступ ко всем проектам установки; храните его приватно.

Попробовать без модели

Создайте ID community-garden с типом «Обычный проект» и импортируйте examples/general-project.json. Экспортируйте, правьте обычным редактором и импортируйте снова. Предыдущие ревизии сохраняются. Данные примера вымышленные.

API и ревизии

Перед обновлением прочитайте проект GET. PUT заменяет name, type, description, archived и roadmap. Передайте прочитанную revision в If-Match. При 409 перечитайте состояние и согласуйте изменения. Git имеет отдельную ревизию, первоначально 0. Полная схема: /openapi.json.

Статус и доказательства

done означает переданную приёмку, а не независимую проверку. Процент плана считает гейты с одинаковым весом, а не готовность продукта или трудозатраты. Даты показывают календарные интервалы. Git не доказывает происхождение ветки.

Удалённый доступ

По умолчанию сервер слушает loopback. Прямой сетевой запуск требует явного списка хостов и TLS. Предпочтителен доверенный HTTPS proxy или приватный туннель с loopback backend. Приложение не настраивает firewall.
