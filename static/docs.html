Kontur help

A single-owner dashboard for explicit project snapshots. Use an HTTP-capable agent, a script, or JSON import. No model or Git is required.

Access

Open http://127.0.0.1:8766 after starting run.py. Read the generated key in data/api-token.txt locally and enter it in the browser. Every /api/v1 request requires Authorization: Bearer <key>. Keep the key private; it grants access to every project in this installation.

Try without a model

Create ID community-garden with type General project, then import examples/general-project.json. Export, edit in an ordinary editor and import again. Previous revisions are retained. Example data is synthetic.

API and revisions

GET projects before updating. PUT replaces name, type, description, archived and roadmap. Send the read revision in If-Match. A 409 requires rereading and reconciliation. Git snapshots have their own revision, initially 0. /openapi.json is the full machine-readable contract.

Status and evidence

done is reported acceptance, not independent verification. Plan percentages count equally weighted gates, not product readiness or effort. Dates show calendar intervals. Git graphs do not prove branch provenance.

Remote access

The default listener is loopback. Direct non-loopback binding requires explicit allowed hosts and TLS. Prefer a trusted HTTPS proxy or private tunnel with the backend on loopback. The application does not configure your firewall.
