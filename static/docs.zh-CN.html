Kontur 帮助

面向单一所有者的项目快照看板。可通过 HTTP 代理、脚本或 JSON 导入使用。不需要模型或 Git。

访问

启动 run.py 后打开 http://127.0.0.1:8766。在本机读取 data/api-token.txt 中生成的密钥，然后输入浏览器。所有 /api/v1 请求需要 Authorization: Bearer <密钥>。该密钥可以访问实例中的所有项目，请勿公开。

不使用模型试用

创建 ID 为 community-garden 的通用项目，然后导入 examples/general-project.json。导出后用普通编辑器修改，再导入。历史版本会保留。示例数据是虚构的。

API 与版本

更新前先 GET 项目。PUT 替换 name、type、description、archived 和 roadmap。在 If-Match 中发送读取的 revision。遇到 409 时重新读取并协调修改。Git 有独立的版本号，初始值为 0。完整结构见 /openapi.json。

状态与证据

done 是报告的验收状态，不是独立验证。计划百分比按同等权重的里程碑计算，不代表产品完成度或工作量。日期显示日历区间。Git 图不能证明分支来源。

远程访问

默认只监听 loopback。直接监听网络地址必须配置明确的主机白名单和 TLS。建议使用可信 HTTPS 代理或私人隧道，让后端保持 loopback。应用不会配置防火墙。
